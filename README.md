# EmployeeManagementProgram
관리자 계정을 로그인하여 DB에 등록된 사원 정보를 조작하는 CRUD 프로그램

# 제작 기간
2022.09 ~ 2022.12 (리팩터링: 2026.11)

# 제작 기술
- Java Swing
- MySQL
- MySQL Connector/J 8.0.25

# 실행
- 진입점: `emp.Main` (IntelliJ Run Configuration의 Main class)
- JDK 11
- DB 설정: `config/db.properties` (기본값 `root` / `1234`, DB `employeedb`)
- JDBC 드라이버: 프로젝트 루트의 `mysql-connector-java-8.0.25.jar`
- 최초 실행 시 DB·테이블·기본 관리자(`admin` / `1234`)를 자동 생성합니다.
- 수동 스키마: `사원관리 프로그램 DB생성 쿼리.sql`

# 주요 기능
## 1. 로그인
- DB의 관리자 테이블의 정보를 읽어와 로그인
- 관리자 테이블의 정보와 다를 시 로그인 실패
- 프로그램 종료 버튼

## 2. 사원 정보
- DB의 사원 테이블의 번호, 이름, 생년월일, 주소, 이메일, 휴대전화, 직위 수정, 삭제
- 프로필 이미지 불러오기·미리보기·삭제 (jpg/jpeg/png, DB BLOB 저장)
- 이미지 변경은 미리보기 후 **수정**을 눌러야 DB에 반영
- 사원의 번호, 이름을 테이블에 표시하고 테이블 행 클릭 시 좌측 텍스트 필드에 해당 사원의 정보가 표시
- 사원의 번호, 이름을 필터링 및 조회하여 테이블에 표시
- 테이블에 전체 사원 정보를 다시 표시하고 좌측 텍스트 필드를 초기화하는 새로고침 버튼
- 번호는 읽기 전용, 삭제 전 확인, 입력값(생년월일 YYYYMMDD·이메일·휴대전화) 검증

## 3. 사원 등록
- 이름, 생년월일, 주소, 이메일, 휴대전화, 직위를 입력하여 사원 등록
- 번호는 자동 넘버링되어 입력 불필요
- 프로필 이미지 추가 (jpg/jpeg/png, 등록 시 함께 저장)
- 텍스트 필드를 초기화하는 다시 작성 버튼

## 4. 파일
- 관리자 계정 로그아웃
- 프로그램 종료

## 5. 도움말
- 제작자 및 저작권 표기 창
